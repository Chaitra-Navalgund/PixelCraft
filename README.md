# PixelCraft — Frontend Intern Static Webpage

## Files
- `index.html` — semantic webpage structure
- `style.css` — layout, styling, and responsive breakpoints
- `report.md` — design decisions, implementation notes, and testing plan

## Run in VS Code
1. Extract the ZIP file.
2. Open the extracted `pixelcraft_frontend_intern_task` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Resize the browser or use Chrome DevTools' device toolbar to test the responsive layout.

## Before submission
- Test desktop, tablet, and mobile widths yourself.
- Fix any issue you observe and record the actual result in `report.md`.
- Take screenshots if your internship portal accepts supporting evidence.
- Keep all three deliverables together.
- The design and sample projects are fictional concepts for this task.
